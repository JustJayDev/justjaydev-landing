# JustJayDev · The Forge
Live at: https://nightforgeio.github.io/justjaydev-landing/
Jay (JustJayDev) — builder, developer, gamer. Forged, not built.

Single-file, dependency-free build. WebGL molten-metal forge background, iron/ember/gold palette, Bitter serif + Azeret Mono type. Two experiences based on device detection:
- **Desktop** — editorial single-page layout with anvil heat panel and row hero.
- **Mobile** — tabbed app (Home · Work · Log · Links) with a bottom tab bar.

## Stack
- Vanilla HTML/CSS/JS — zero build step, no frameworks.
- WebGL 1.0 shader forge (1,400 metal particles + 700 rising sparks).
- matchMedia device detection (`data-device`) + fine-pointer gating (`data-fine`).
- Total weight ~300KB (WebP icons, 6 woff2 fonts).

## Design
**Forge** concept: iron (#0a0604) / ember (#ff6a2b) / gold (#e8a13a). Bitter (serif) + Azeret Mono (display). Editorial asymmetric layout with tooling list rows rather than cards.
## Deploy
Push to `main` → GitHub Pages serves the repo root.
